# UI：画面上的菜单、状态和视频怎样工作

本章对应 `Source/SuzuneMatsuri/Matsuri/UI/` 的全部 **26 个文件（13 对头文件/实现文件）**。`.h` 声明控件类、可调用接口和控件引用；`.cpp` 用 C++ 创建 UMG 控件树、绑定事件并实现行为。以下同名头文件和实现文件合并讲解；头文件内的小函数也列出。匿名 lambda 不单列函数，但涉及异步流程时解释其用途。

这些文件主要负责“显示和把操作交给游戏系统”。生命值、伤害、技能冷却等真正的规则位于 Core、Combat、Boss。UI 中看到 `OnClicked.AddDynamic`，意思是“按下按钮时调用指定函数”；看到 `OnRunChanged`，意思是“游戏状态改变后通知界面刷新”。

## 1. MatsuriUIStyle.h / MatsuriUIStyle.cpp：所有菜单共用的外观

源码：[头文件](../../SuzuneMatsuri/Source/SuzuneMatsuri/Matsuri/UI/MatsuriUIStyle.h)、[实现](../../SuzuneMatsuri/Source/SuzuneMatsuri/Matsuri/UI/MatsuriUIStyle.cpp)。

`MatsuriUI` 命名空间保存朱红、金色、纸白、夜蓝等颜色，并提供控件工厂。它没有独立运行的游戏对象。

| 函数 | 作用 |
|---|---|
| `MakeText` | 创建文字控件，统一字号、字体、颜色、阴影和居中方式，返回 `UTextBlock*`。 |
| `MakeButton` | 创建标准按钮，配置正常/悬停/按下颜色、悬停和确认音效，以及内部文字和留白。它不决定按钮点击后的业务。 |
| `MakeSmallButton` | 复用标准按钮，再缩小字号和内边距。 |
| `SetButtonLabel` | 修改按钮内的文字；可用金色突出当前选择，空指针时安全忽略。 |
| `MakePortrait` | 根据纹理、UV 裁剪区域和尺寸创建头像；没有纹理返回空，调用者可以省略头像。 |
| `InstallModalCard` | 建立根 Overlay，把内容放在居中的夜蓝面板内；这里只建画面，不负责暂停世界。 |
| `MakePanel` | 用指定背景色、内边距包住一组控件，返回 Border。 |

## 11. MatsuriCinematicWidget.h / .cpp：剧情 CG 和角色大招短片

源码：[头文件](../../SuzuneMatsuri/Source/SuzuneMatsuri/Matsuri/UI/MatsuriCinematicWidget.h)、[实现](../../SuzuneMatsuri/Source/SuzuneMatsuri/Matsuri/UI/MatsuriCinematicWidget.cpp)。`EMatsuriCinematic` 的八项对应三段入场、战败、胜利和三位英雄大招。`UMatsuriCinematicWidget` 保存 MediaPlayer、MediaTexture、FileMediaSource、MediaSound，以及播放前的暂停/鼠标状态。

| 函数 | 作用 |
|---|---|
| `IsUltimateEnabled` | 读取 `matsuri.UltimateCinematic`，仅控制大招电影是否启用。 |
| `RelativeMoviePath` | 将电影枚举映射到 `Movies/*.mp4`，对枚举索引做范围保护。 |
| `AbsoluteMoviePath` | 将上述相对路径拼到工程 Content 目录下。 |
| `TryPlay` | 用电影枚举调用通用的 `TryPlayPath`。 |
| `TryPlayPath` | 先检查文件和控件创建；失败立即返回 false，不执行异步完成回调。成功时保存原暂停/鼠标状态，将界面放到 1100 层，切到 UI 输入、显示鼠标、暂停世界，然后开始打开文件。 |
| `NativeOnInitialized` | 建立视频图像和右下角 Skip 按钮。 |
| `Begin` | 保存完成回调及最大播放时长，创建媒体对象/音频组件并连接事件，打开文件；安装暂停中仍能推进的 Core Ticker，打开超时后自动结束。 |
| `HandleMediaOpened` | 标记实际打开、取消打开超时并调用 Play；播放失败则结束。有时长限制时从此刻开始计时，例如大招的 2.5 秒限制。 |
| `HandleMediaOpenFailed` | 异步打开失败时进入统一结束流程，避免卡在黑屏或暂停。 |
| `HandleMediaEnd` | 自然播完时进入统一结束流程。 |
| `Finish` | 防重入；移除两个 Ticker、关闭媒体、清理音频、关闭界面，再恢复游戏并通知调用者。 |
| `RestoreAndNotify` | 恢复原暂停值和鼠标可见性，输入设为 GameOnly；移走完成委托后执行一次。它没有保存并还原任意旧输入模式，而是由后续结算等调用方再设置需要的 UI 模式。 |
| `NativeDestruct` | 外部关闭控件时同样清理 Ticker/音频；正常世界中必要时恢复并通知，世界正在销毁时解除回调，避免跨地图执行旧流程。 |
| `NativeOnKeyDown` | Escape、Enter、Space 都跳过；其他键交给父类。 |
| `HandleSkipClicked` | 按 Skip 时转调 `Finish`。 |
| `IsFinished` | 返回是否已经结束，供测试和外部查询。 |
| `HasMediaOpened` | 返回后端是否实际成功打开视频；创建了控件不代表视频已经播放。 |

关键区别：调用 `TryPlay` 得到 true 只是“已经接手播放流程”，后续仍可能打开失败。缺文件的立即 false 和异步失败的完成回调是两种不同路径，调用者需要都能接着推进游戏。

| `Finish` | 防止重复结束，移除控件，恢复暂停/鼠标并设 GameOnly 输入，执行一次完成回调。 |
| `NativeOnKeyDown` | Enter/Space 下一句，Escape 结束。 |
| `HandleNextClicked` | 按钮回调，转调 `NextLine`。 |
| `HandleSkipClicked` | 按钮回调，转调 `Finish`。 |
| `GetLineIndex` | 返回当前句索引。 |
| `IsFinished` | 返回章节是否结束。 |

## 从一次点击理解整个 UI 调用链

`主菜单 HandleStartClicked → 选角 ChooseHero → Flow::StartNewRun → RunSubsystem 建立状态 → TravelTo → Loading → 新关 GameMode → Cinematic → HUD`。

失败时是 `GameMode 接受致命伤害 → ReplayDirector + ReplayWidget → 战败 Cinematic → GameOverWidget`；成功通关普通层后是 `VictoryWidget → OmamoriWidget → ContinueWithCharm → 下一关`。这些流程中，Widget 展示画面和响应操作，GameMode/Subsystem 决定什么时候完成、失败或推进。
